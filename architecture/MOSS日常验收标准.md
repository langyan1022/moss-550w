# MOSS 日常使用验收（v2 严苛版）

目标为 90 分，且**先过一票否决硬门禁，再谈分数**。验收使用日常 Windows 配置、当前 550W 页面、当前 MOSS 音色和单独测试会话。真实服务与可控故障均可纳入。每项记录入口、测试动作、结果、耗时和适用范围。隔离 NAS、合成录音和窗口的结果单独注明。

> **关于此前 96/100 的复盘与口径收紧（2026-11-23）**：旧版 96/100 主要验证了“单模型顺风局 + 后端单测 + 语音延迟”，却漏掉了真实用户随手一用就会踩到的 5 类线上盲区：（1）前端跨模块方法名写错（如大脑中枢点态势简报触发 `voice.isTtsEnabled is not a function`）；（2）视觉资源在 CSS 遮罩下退化成空白黑框或纯白圆球（如领航员纹章与 BSC 标识）；（3）多云模型行为分化（Kimi 情绪倾诉误调 `play_song`、首行回显原句、上游偶发超时）；（4）口语儿化音、情绪吐槽分流与句内过长死停顿；（5）直播/运行中瞬时 CPU 尖峰误弹红条与无摄像头静默失效。自 v5.3 起启用下述 **v2 硬门禁 + 重算分值**，彻底封堵“高分低体验”。

## 零容忍发布硬门禁（`prototype/release_gate.py`）

任一硬门禁未通过，**禁止发布**，且验收总分最高封顶 **75 分**：

1. **静态与跨模块契约门禁（Stage 1）**：核心 Python 语法、`node --check`、`i18n.js` 中英键 1:1 零差额（668/668）、JS 控制器导出方法/DOM ID/`/api/*` 路由跨模块契约审计、`fui_lint.py` 0 blocker / 0 major / 0 minor、`check_model_release.py` 认证 3D 模型零篡改。
2. **核心、对抗与 230 条黄金基准门禁（Stage 2）**：数字与日期读法（24/24）、对话质量单测与 HTTP、儿化音/三性格/音乐防幻觉单测（39/39）、**230 条分层日常黄金样本库**（45 儿化音 + 40 ASR 同音/热词纠偏 + 35 安全防幻觉 + 30 三性格与播报净化 + 25 数字日期 + 5 组×11 轮共 55 轮混合上下文连续对话）、首行回显清洗、云端瞬时超时单次静默重试、持续起音静音裁剪、5 手势分类与 CPU 三次连采防抖全部通过。
3. **语音奇偶与 RTX 3070 Ti 真声流畅度门禁（Stage 3）**：`verify_fui_speech_latency.py --mode parity` 9/9 通过（含流式预合成、打断、独立停播、成组预取）；真实 GPU 预热后首条 `warm` 语音 `head_s ≤ 0.12 s`、句内最长停顿 `≤ 0.45 s`。
4. **真 Edge 全入口实点与零报错门禁（Stage 4a，默认独立端口 + `--mute-audio` 静音隔离运行）**：自动点击大脑中枢 5 页（含生成态势简报与夜间做梦）、设置 5 页与 3 性格往返切换、手势按钮与无设备提示窗、点歌与媒体完整↔精简条及 `‹/›` 切歌、历史全文检索与导出 MD、本地文档查看器上传、`/mobile` 390 px 零溢出、中英切换，强制 **`0 pageerror` + `0 console.error`**，并核验 `/conversation-assets/*.glb` 缓存头与 `moss-render.js` 缓存 + Gzip 压缩生效。
5. **关键视觉资产像素级自检门禁（Stage 4b）**：逐一打开 4 份情报档案 × 2 页（8 枚徽章）并对其截图执行前景像素占比（`1.2%–85%`）与边缘梯度密度（`edge/fg ≥ 0.09`）自动核验，杜绝纯黑空白与纯白圆球遮罩，同时保留人工目视复检截图。
6. **跨模型与实机声学边界（不达标不得给满分）**：
   - 多云模型实测须覆盖 Qwen / DeepSeek / Kimi 三家（不得只测单一家即宣称通过）。
   - 实体房间声学（`run_room_acoustic_acceptance.py --mode full` 30 分钟实体扬声器 + 麦克风安静/回声/环境声三工况）与实体 NAS/实机摄像头长测在未真机跑完前，对应细项明确留空扣分，**绝不以离线夹具冒充实机满分**。
